# ספקי תוכן: איך מחברים מאגר אקורדים מורשה

## המצב היום

| שכבה | מקור | מה מקבלים | מצב |
|---|---|---|---|
| קטלוג (חיפוש) | MusicBrainz API | שירים, אמנים, שמות חלופיים, שנים, סגנונות, כותבים, מזהי יצירה ו-ISRC | **פעיל** |
| אקורדים | גיליונות אישיים | אקורדים שהמשתמש הזין בעצמו, נשמרים בדפדפן שלו | **פעיל** |
| אקורדים | נחלת הכלל | 6 שירים מסורתיים או שהזכויות עליהם פקעו, בעיבוד בסיסי של השירון | **פעיל** (כיסוי מזערי) |
| אקורדים | API מורשה (`remoteApi.ts`) | כל קטלוג שיש עליו רישיון | **לא מחובר – זה החלק החסר** |

## מה נבדק, ולמה אין כיסוי רחב עדיין

- **MusicBrainz**: נתונים פתוחים (ליבה ב-CC0), API חינמי עם CORS, עד בקשה אחת בשנייה. מכסה מיליוני הקלטות, כולל שירים בעברית. לא מספק אקורדים ולא מילים.
- **Ultimate Guitar, Tab4u, Nagnu וכד'**: אין API ציבורי, ותנאי השימוש אוסרים העתקה אוטומטית. השירון מציג רק **קישורי חיפוש** אליהם.
- **Songsterr**: טאבים מורשים, אבל אין API רשמי ומתועד לשימוש צד שלישי. מוצג כקישור בלבד.
- **Chordify**: API לשותפים בהסכם מסחרי (אקורדים בלבד, בלי מילים).
- **מילים**: הצגת מילים מלאות של שיר מסחרי דורשת רישיון. ספקים מסחריים מורשים: Musixmatch (בתוכנית החינמית רק קטע מהמילים), LyricFind. בישראל: אקו״ם או המו״לים.
- **מאגרי מילים קהילתיים (למשל LRCLIB)**: לא חוברו, כי אין להם בסיס רישוי ברור להצגת מילים מלאות.

## הפתרון המעשי לכיסוי רחב

1. **הסכם תוכן עם מאגר אקורדים קיים** (למשל אתר אקורדים ישראלי שכבר משלם תמלוגים ומחזיק את הזכויות על עיבודי האקורדים), כולל גישת API או ייצוא קבצים.
2. **רישיון מילים**: לשירים ישראליים דרך אקו״ם או המו״לים, ולשירים בינלאומיים דרך ספק כמו LyricFind או Musixmatch Enterprise.
3. **שרת תוכן קטן** שמחזיק את הגיליונות המורשים ומממש את החוזה שלמטה. ההתאמה לקטלוג נעשית לפי מזהי MusicBrainz (הקלטה, יצירה), לפי ISRC, ולבסוף לפי שם שיר ואמן.
4. בבנייה מגדירים `VITE_CHORDS_API_URL=https://chords.example.com/v1`. אין צורך לשנות שום דבר אחר באתר.

## החוזה של ספק API מורשה

```
GET {VITE_CHORDS_API_URL}/sheets?recording={mbid}&work={mbid,...}&isrc={isrc,...}&title={title}&artist={artist}
```

תשובה (200):

```json
{
  "sheets": [
    {
      "id": "12345",
      "title": "שם השיר",
      "artist": "שם האמן",
      "key": "Am",
      "capo": 2,
      "chordpro": "{בית 1}\n[Am]מילים עם [F]אקורדים",
      "source": { "name": "שם המאגר", "license": "רישיון מס׳ ... בתוקף עד ...", "url": "https://..." }
    }
  ]
}
```

- `chordpro`: אקורד בסוגריים מרובעים ממש לפני ההברה, שורה ריקה בין קטעים, כותרת קטע `{פזמון}`.
- גיליון בלי `source.license` נדחה ולא מוצג.
- 404 או רשימה ריקה פירושם "אין אקורדים". שגיאה אחרת מוצגת למשתמש כתקלה זמנית, ולא כ"אין אקורדים".
- השרת צריך לאפשר CORS מהדומיין של האתר.

## הוספת ספק מסוג אחר

מממשים את `ChordProvider` (`src/content/types.ts`) ומוסיפים אותו לרשימה ב-`src/content/registry.ts`:

```ts
export const myProvider: ChordProvider = {
  id: 'my-source',
  name: 'שם המקור',
  description: 'מה המקור ומה בסיס הרישוי',
  isEnabled: () => true,
  quickCheck: (ref) => undefined, // true רק אם ידוע בוודאות, בלי רשת
  async find(ref, signal) { return []; },
};
```

עמוד השיר, סימון "אקורדים" בתוצאות ועמוד המקורות משתמשים ברשימה הזו אוטומטית.
